A public proof-of-concept exploit named SignDrop targets the Common Log File System (CLFS) authentication mitigation in Windows. It converts a standard user token into NT AUTHORITY\SYSTEM and can blind antimalware engines. The privilege escalation weakness has no CVE identifier and no patch as of November 11, 2026, and Microsoft has not confirmed the claims.
